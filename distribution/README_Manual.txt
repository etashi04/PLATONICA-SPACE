PLATONICA SPACE 비공식 한국어 패치 {{VERSION}} - 수동 설치판

이 패키지에는 실행 파일이 없습니다. 아래 파일을 직접 복사하여 설치합니다.

[설치]
1. PLATONICA SPACE와 Steam을 종료합니다.
2. Steam 라이브러리에서 PLATONICA SPACE를 우클릭하고 [관리] → [로컬 파일 탐색]을 누릅니다.
3. 이 ZIP의 모든 파일과 폴더를 게임 설치 폴더에 그대로 복사합니다.
4. 폴더 병합과 파일 덮어쓰기를 승인합니다.
5. 게임을 실행합니다. 첫 실행은 BepInEx 초기화 때문에 평소보다 오래 걸릴 수 있습니다.
6. BepInEx 콘솔에 KR_PATCH_READY가 표시되면 정상입니다.

[제거]
게임을 종료한 뒤 BepInEx\plugins\KR.LanguageFontPoc 폴더를 삭제합니다.
BepInEx까지 제거하려면 Steam의 [설치된 파일] → [게임 파일 무결성 검사]를 실행합니다.

[주의]
- Steam 앱 ID 3846480, 게임 빌드 24960315, Windows x64 기준입니다.
- 게임 업데이트 후에는 새 패치 버전의 지원 여부를 확인하세요.
- 게임 원본 파일과 세이브 파일은 수정하지 않습니다.

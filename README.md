# PLATONICA SPACE 한국어 패치

PLATONICA SPACE 비공식 한국어 패치 작업 저장소입니다.

현재 상태는 플레이 테스트와 미번역·UI 표시 문제를 수정하는 개발 단계입니다. 완성된 배포판으로 확정되기 전까지는 테스트용으로만 사용해 주세요.

## 저장소 구성

- `src/KR.LanguageFontPoc`: BepInEx IL2CPP 런타임 패치 소스
- `package/BepInEx/plugins/KR.LanguageFontPoc`: 현재 테스트 중인 플러그인, 한글 폰트 번들, 번역 데이터

## 테스트 설치

게임에 호환되는 BepInEx IL2CPP 환경이 구성되어 있다는 전제에서 `package` 폴더의 내용을 게임 설치 폴더에 복사합니다.

순정 게임 파일과 세이브 파일은 별도로 백업하고 테스트해 주세요.

## 현재 확인된 범위

- 본편 대사 및 선택지 한국어 출력
- 옵션과 인벤토리 UI 한국어 출력
- 기억의 조각·인물 상세 설명 한국어 출력
- 아이템·키워드 목록의 잔여 일본어 보정
- 한국어 FontAsset 런타임 적용

## 주의

- 비공식 팬 패치입니다.
- 원본 게임 파일은 이 저장소에 포함하지 않습니다.
- 대응 게임 버전, 설치·삭제 절차, 사용 폰트와 라이선스는 정식 배포본 제작 단계에서 최종 정리할 예정입니다.
